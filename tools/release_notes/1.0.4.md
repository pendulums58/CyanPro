- **클라이언트 자동 업데이트 추가.** 이 버전부터는 새 버전이 나오면 실행할 때 업데이트 여부를 묻고, 받으면 자동으로 설치 후 재시작합니다. 설정의 "클라이언트 업데이트하지 않기"로 끌 수 있습니다. 1.0.4 자체는 한 번 직접 받아 주세요.
- **액세스 소재 버그 수정.** 장착 카드를 장착한 몬스터를 액세스 소환의 어드민으로 삼으면 장착 카드가 필드에 남던 문제를 고쳤습니다. 이제 엑시즈 소재가 될 때와 똑같이 장착 카드는 파괴되고, 효과 리셋 등 필드를 떠날 때의 처리가 모두 적용됩니다.
- **배포 파일 정리.** 개인 덱과 기본 예시 덱(Tactical-Try)을 빼고, 설정 파일(system.conf)의 닉네임·접속 주소 같은 개인 설정을 기본값으로 되돌렸습니다.
